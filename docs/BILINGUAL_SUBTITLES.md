# 手动中文字幕：导入、核对与逐句编辑

本文描述 **0.9.0 稳定版候选**中的手动中文字幕。字幕功能已通过 G7 独立测试与用户验收；本轮 Listen 布局优化仍待独立验收，公开源码目前为 v0.6.1。此功能用于显示用户已有的中文译文，不包含自动翻译服务、翻译模型或文本上传。

## 使用入口

先在 Library 打开已有、通过完整性校验的音频导出，再到 Listen 查看字幕。字幕显示模式与 Settings 的界面语言、主题独立：

| Listen 模式 | 行为 |
|---|---|
| **English Only / 仅英文** | 默认模式，只显示原英文字幕；不会删除已经保存的中文 |
| **English + Chinese / 英文 + 中文** | 英文在上、中文在下；中文字号为英文字号约 80%，使用次要文字颜色 |

模式选择立即生效并保存到 `preferences.json` 的 `subtitle_mode`，稳定值为 `english/bilingual`。旧偏好缺少此字段或字段值无效时，回退 `english`。中文 GUI 不会自动启用双语字幕；改回英文 GUI 也不会清除中文译文。

英文 SRT 是唯一时间轴。双语共用同一个 cue 的点击跳转、当前句高亮和跟随滚动；切换显示模式或修改译文不重新合成音频、不调整英语起止时间。未填中文的句子继续显示英文，不阻止播放。

## 听读空间与专注模式

Listen 顶部保留紧凑的标题、副标题与 **Focus view / 专注模式**。字幕列表随窗口分配剩余空间，主要滚动发生在列表内部；时间戳单独占一列，中英文正文共用同一左边缘。英文仍使用用户选择的 12–40 px 字号，中文约为其 80%，不会为了多显示几行而自动缩小正文。

没有打开任务时，**No session loaded / 未加载会话** 显示在字幕区域中，可通过 **Open Library / 打开资料库** 打开历史任务。加载后空状态消失。任务信息仍可在默认折叠的 **Session details / 会话详情** 中查看，不占用常驻右栏。

开启 Focus view 会收起次要界面元素，为字幕腾出空间。播放/暂停、进度与跳转、字号、字幕模式和退出专注模式的入口仍然可用。退出时恢复常规布局，不重新加载音频、不重新合成，也不修改当前播放位置、中文译文或英文 SRT。窗口大小、主题与语言的真实桌面表现仍以对应版本的测试记录为准。

## 导入已有译文

点击 **Import Chinese / 导入中文字幕**，选择本地 UTF-8 `.srt` 或 `.txt` 文件。支持 UTF-8 BOM。文件至多 16 MiB；每句译文至多 16 KiB（按 UTF-8 字节计算）。

| 格式 | 必须满足的条件 | 程序不能证明的事项 |
|---|---|---|
| SRT | cue 数量、从 1 开始的连续编号、每句开始与结束毫秒数都与原英文完全一致；每句有非空文本 | 相同时间与编号不证明语义翻译正确，也不证明译文没有写错句子 |
| TXT | 每个英文 cue 对应一条非空物理行，行数与 cue 数完全相同，顺序一一对应 | 相同行数不能发现语义错位；必须人工检查每一对英文和中文 |

TXT 的换行符可为 LF、CRLF 或 CR，允许文件结尾有一个正常换行；空行和纯空白行会被拒绝，程序不会悄悄跳过空行来移动映射。需要给一句中文分行时，可先逐句编辑；不要把一条译文拆成多条 TXT 记录。界面自动换行只是显示效果，不是新的 cue。

例如英文有两个 cue，TXT 应当只有两条正文记录：

```text
安静的清晨从一句清晰的话开始。
慢慢听，然后再听一次。
```

导入成功后，会打开 **Review Chinese subtitle mapping / 核对中文字幕对应关系**，完整列出每个英文 cue 及拟导入的中文。查看全部对应关系，确认内容和顺序后，勾选默认未选中的确认框，再点击 **Confirm and save Chinese / 确认并保存中文**。取消或关闭弹窗不保存新译文。已有译文也必须经过这个确认流程才能被整批替换。

此确认只批准本地译文映射，不构成任何在线 TTS 或未来翻译服务的上传许可。原始英语与中文均按纯文本显示，不作为 HTML 或界面翻译字符串解析。

## 逐句补充或修改

在 Listen 选中一条字幕，点击 **Edit selected Chinese / 编辑选中句译文**。上方英文只读，下方可填写或修改该句中文；保存只更新这一句对应的本地译文记录。

没有整份译文时，也可以直接逐句填写：已填句显示中文，其余记录保持缺失。编辑器不允许保存空白、纯空白、无效控制字符或超过 16 KiB 的内容；本版没有通过“保存空白”删除已有译文的操作。取消会保留旧内容。选择字幕和实际播放位置使用现有播放器行为，编辑不会修改 cue 时间。

如果同一份译文在弹窗打开期间被其他窗口或进程修改，保存会提示冲突，要求重新打开并检查，不用旧内容覆盖新文件。英文 SRT 在编辑或导入期间变化时，也必须先重新打开并验证该导出。

## 保存位置与绑定规则

默认目录是：

```text
~/Library/Application Support/Lextide/desktop/translations/<English-SRT-SHA256>.zh-CN.json
```

使用 `lextide gui --data-dir /your/chosen/directory` 时，译文保存在该数据目录下的 `translations/`。这些 JSON 是独立的本地附加文件，不写回英文 SRT、MP3、历史 job/task manifest 或已批准的朗读稿。

| 身份字段 | 用途 |
|---|---|
| `source_srt_sha256` | 绑定英文 SRT 的精确文件字节；仅改换行或空格也会改变身份 |
| `cue_digest` | 汇总有序 cue 编号、时间和英文文本哈希 |
| 每条 cue 的 `index/start_ms/end_ms/source_text_sha256` | 复核该中文记录确实属于这一条英文字幕 |
| `schema_version/language` | 本版独立译文 schema 为 `1`，语言标识为 `zh-CN`；不改变 job/task 的 schema |

文件名绑定内容，因此英文 SRT 字节完全相同的导出共用同一份译文；不同 SRT 版本不会按标题或路径猜测匹配。JSON 中缺失译文使用 `null`，不把空字符串当成已翻译内容。

保存通过锁、当前版本指纹检查与同目录原子写入完成；这些保护检测意外变化，不是针对恶意同时改写所有文件的数字签名。请通过界面维护译文，不要手工修改哈希来跳过绑定校验。

## 常见问题

| 现象 | 处理方式 |
|---|---|
| SRT 导入被拒绝 | 对照当前英文 SRT 检查 cue 数量、连续编号和每个时间戳；本版不自动重排、模糊匹配或重定时 |
| TXT 导入被拒绝 | 保存为 UTF-8，核对每条物理行与英文 cue 的数量，移除意外空白记录并重新检查语义顺序 |
| 双语模式仍有英文单行 | 对应 cue 没有中文；选中该句补充，或导入并审核完整译文 |
| 中文附加文件损坏或身份不符 | 界面显示警告，英语播放保留；单句编辑会停用。重新打开检查，或完整导入并确认后替换损坏附加文件 |
| 提示英文变化或译文冲突 | 重新打开导出并核验，重新查看映射或单句内容后再保存 |
| 中文字体、长句或最大字号显示不完整 | 记录窗口尺寸、主题、12/18/40 px 与截图，交由对应平台测试；Mac 结果不能替代 Windows 验收 |
